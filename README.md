# JavaPlayground

An interactive web application for experimenting with Java String methods in real time. Easily test, learn, and understand how different string operations work with instant results and clean visual output.

---
##  Features

###  Java String Methods Support
Test common Java String operations including:

- `length()`
- `charAt()`
- `substring()`
- `indexOf()`
- `contains()`
- `startsWith()`
- `endsWith()`
- `toLowerCase()`
- `toUpperCase()`
- `trim()`
- `replace()`
- `split()`
- and more!



## 📂 Installation

```bash
git clone https://github.com/your-username/JavaPlayground.git

cd JavaPlayground
```

Open `index.html` in your browser.
